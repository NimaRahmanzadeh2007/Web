## 🚀 Getting Started

### Clone

```bash
git clone https://github.com/YOUR_USERNAME/github-user-dashboard.git
cd github-user-dashboard
```

### Run

Open `index.html` in your browser, or use a local server:

```bash
python -m http.server 5500
```

Then visit:

```text
http://localhost:5500
```

Enter a public GitHub username and press **Search**.

---

## 🔐 API & Privacy

This project uses the **public GitHub REST API** and does not require GitHub authentication for basic usage.

It does **not** access:

* Private repositories
* Private messages
* Passwords
* Private account information

Because unauthenticated GitHub API requests are rate-limited, excessive requests may temporarily prevent new searches.
